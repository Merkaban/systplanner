# SySt®-Modulplaner

Erfassung absolvierter und geplanter Fortbildungen am SySt®-Institut und ihre Anrechnung auf die Module der 4-jährigen Ausbildung.

## Ausbildung

**Ausbildung**:
Die 4-jährige SySt®-Ausbildung „Systemische/r BeraterIn bzw. TherapeutIn“, auf die Fortbildungen angerechnet werden.
_Avoid_: Weiterbildung, Studiengang

**Abschluss**:
Das angestrebte Ziel der Ausbildung: BeraterIn (Module 1–8, 94 Tage) oder TherapeutIn (Module 1–7, 90 Tage).
_Avoid_: Zertifikat, Titel

**Modul**:
Ein thematischer Bereich der Ausbildung mit einem festen Bedarf an Tagen.
_Avoid_: Baustein, Fach

**Untermodul 4a**:
Teil von Modul 4; Tage auf 4a zählen zu Modul 4, höchstens 8.

**Bedarf**:
Die Anzahl Tage, die ein Modul für den gewählten Abschluss braucht.
_Avoid_: Soll, benötigte Tage

**Überbelegung**:
Tage, die einem Modul über seinen Bedarf hinaus zugeteilt sind (bei 4a: über 8); sie sind verschwendet.
_Avoid_: Überbuchung, Überschuss

## Fortbildungen

**Fortbildung**:
Eine erfasste Veranstaltung, deren Tage auf die Ausbildung angerechnet werden können; entweder Jahresausbildung oder Seminar.
_Avoid_: Kurs, Veranstaltung, „Seminar“ als Oberbegriff

**Jahresausbildung**:
Eine 1-jährige Fortbildung, z. B. SyDe, Orga, SFT.
_Avoid_: 1-jährige Ausbildung, Ausbildung

**Seminar**:
Eine Fortbildung von wenigen Tagen, z. B. die Einführung in die Strukturaufstellungen oder GPA.
_Avoid_: Workshop

**Status**:
Ob eine Fortbildung absolviert oder geplant ist; nur geplante lassen sich für Was-wäre-wenn ausblenden.

**Fremdfortbildung**:
Eine Fortbildung eines anderen Instituts; bis zu 40 Tage anrechenbar.
_Avoid_: externes Seminar, Fremdseminar

**Katalogeintrag**:
Eine Vorlage für eine Fortbildung samt Anrechnungsregel; beim Hinzufügen wird sie kopiert, spätere Katalogänderungen wirken nicht zurück.
_Avoid_: Template

**Anrechnungsregel**:
Legt fest, welche Tage einer Fortbildung auf welche Module angerechnet werden: feste Tage plus beliebig viele Wahlblöcke. Ihre Summe sind die anrechenbaren Tage.
_Avoid_: Anrechnung, Regel, Obergrenze je Modul

**Anrechnungsstatus**:
Wie verlässlich eine Anrechnungsregel ist: offen (noch leer, zählt 0 Tage), vorläufig (eingetragen, vom Institut unbestätigt) oder bestätigt.
_Avoid_: Status (das ist absolviert/geplant), Freigabe

**Feste Tage**:
Tage einer Fortbildung, die immer auf ein bestimmtes Modul angerechnet werden.
_Avoid_: Fix-Anteil, Pflichttage

**Wahlblock**:
Eine Anzahl Tage einer Fortbildung, die vollständig auf genau eine von mehreren Optionen angerechnet wird; Aufteilen ist nicht erlaubt.
_Avoid_: Alternative, Variante, flexible Tage

**Option**:
Eine mögliche Aufteilung eines Wahlblocks auf Module, z. B. „M5 8 + M6 2“.
_Avoid_: Variante, Alternative

## Verteilung

**Verteilung**:
Die gewählte Option für jeden Wahlblock aller eingeblendeten Fortbildungen; daraus ergibt sich die Belegung jedes Moduls.
_Avoid_: Zuteilung, Szenario, Verteilungsvariante

**Festhalten**:
Eine gewählte Option eines Wahlblocks so markieren, dass Verteilungsvorschläge sie nicht ändern.
_Avoid_: Sperren, Fixieren

**Ausgeblendet**:
Eine geplante Fortbildung, die für Was-wäre-wenn vorübergehend weder in die Verteilung noch in Vorschläge eingeht.
_Avoid_: deaktiviert, inaktiv

**Angerechnete Tage**:
Die Summe der belegten Tage über alle Module, jeweils höchstens bis zum Bedarf; Überbelegung zählt nicht.
_Avoid_: Fortschritt, Gesamtsumme

**Verteilungsvorschlag**:
Eine vom Planer berechnete Verteilung mit möglichst vielen angerechneten Tagen, die man übernehmen kann.
_Avoid_: Optimierung, Empfehlung
